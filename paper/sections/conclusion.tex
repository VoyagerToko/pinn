\section{Conclusion}
\label{sec:conclusion}

We implemented the current recipe for physics-informed neural networks for incompressible flow in one code
base and tested it on a ladder of six problems against references that were, where necessary, generated or
digitised independently. The representation-side components worked as intended on smooth problems: the
two-dimensional Taylor--Green vortex was solved to $4\times10^{-5}$ and the regularised-lid cavity at
$\Rey=1000$ to 0.27\% of a converged finite-difference field. The constraint- and weighting-side components
need care: imposing boundary data exactly failed wherever the data were incompatible with the equations, and
gradient-norm balancing reinstated that failure through the weights. Two gates depended on the reference as
much as on the network, which argues for stating benchmark gates against references that solve the same
problem to an accuracy well beyond the gate. \pending{one sentence each on C, D, inverse and DeepONet once
measured.} The code, the reference solver, the run logs and the evaluation files needed to reproduce every
number in this paper are in the accompanying repository.
